# Aplicaciones interactivas del curso

Herramientas web creadas para practicar los temas del curso. No requieren instalación: se abren directamente en el navegador.

| Aplicación | Qué hace | Acompaña a | Enlace |
|------------|----------|------------|--------|
| **Tablas de Verdad** | Genera la tabla de verdad de una expresión lógica: conectores AND, OR, NOT, implicación (`->`) y bicondicional (`<->`), con variables `p`, `q`, … | Sesiones 1–2 (lógica proposicional) | [Abrir aplicación](https://true-table-prope-1--true-table-prope.us-east4.hosted.app/) |
| **Función lineal y cuadrática** | Mueve los coeficientes de una recta y de una parábola y observa en tiempo real cómo cambian la pendiente, el vértice y los cortes con los ejes | Sesión 5 (funciones) | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/MisParabolas) |
| **Transformaciones lineales** | Aplica una matriz 2×2 a una figura del plano y visualiza el efecto geométrico de la transformación lineal: rotaciones, escalamientos, reflexiones y cizallas | Sesión 11 (aplicaciones lineales) | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/Transformaciones%20Lineales) |
| **Derivada como límite** | Muestra la recta secante que se convierte en tangente: la derivada como límite del cociente incremental (f(x+h) − f(x))/h cuando h → 0 | Sesión 15 (concepto de derivada) | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/LimiteDerivada) |
| **Función y derivada** | Grafica una función junto a su derivada para leer en el gráfico el signo de f′, los intervalos de crecimiento y los puntos críticos | Sesiones 15–17 (derivadas y optimización) | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/Funcion%20y%20Derivada) |

Las aplicaciones nuevas se irán añadiendo a esta tabla a lo largo del curso. Si más adelante el código fuente de una aplicación se publica en este repositorio, vivirá en una subcarpeta propia: `aplicaciones/<nombre-app>/`.
