# Aplicaciones interactivas del curso

Herramientas web creadas para practicar los temas del curso. No requieren instalación: se abren directamente en el navegador.

| Aplicación | Qué hace | Acompaña a | Enlace |
|------------|----------|------------|--------|
| **Tablas de Verdad** | Genera la tabla de verdad de una expresión lógica: conectores AND, OR, NOT, implicación (`->`) y bicondicional (`<->`), con variables `p`, `q`, … | Lógica proposicional | [Abrir aplicación](https://true-table-prope-1--true-table-prope.us-east4.hosted.app/) |
| **Función lineal y cuadrática** | Mueve los coeficientes de una recta y de una parábola y observa en tiempo real cómo cambian la pendiente, el vértice y los cortes con los ejes | Funciones | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/MisParabolas) |
| **Transformaciones lineales** | Aplica una matriz 2×2 a una figura del plano y visualiza el efecto geométrico de la transformación lineal: rotaciones, escalamientos, reflexiones y cizallas | Álgebra lineal · aplicaciones lineales | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/Transformaciones%20Lineales) |
| **Derivada como límite** | Muestra la recta secante que se convierte en tangente: la derivada como límite del cociente incremental (f(x+h) − f(x))/h cuando h → 0 | Cálculo diferencial · concepto de derivada | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/LimiteDerivada) |
| **Función y derivada** | Grafica una función junto a su derivada para leer en el gráfico el signo de f′, los intervalos de crecimiento y los puntos críticos | Cálculo diferencial · derivadas y optimización | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/Funcion%20y%20Derivada) |
| **Series de Taylor** | Elige una función, el punto de expansión y el número de términos del polinomio de Taylor: la gráfica compara la aproximación con la función exacta y muestra la fórmula de la serie, su intervalo de convergencia y el error absoluto en el punto que elijas | Cálculo diferencial · series de Taylor | [Abrir aplicación](https://www.wolframcloud.com/obj/faperezfl/TaylorSeries) |

Las aplicaciones nuevas se añaden a esta tabla a medida que se publican. Si más adelante el código fuente de una aplicación se publica en este repositorio, vivirá en una subcarpeta propia: `aplicaciones/<nombre-app>/`.
